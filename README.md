透过一扇扇不同寻常的窗户，看见超现实的远方。

## 关于作品

《Uncommon Windows》系列作品使用 **Recraft AI** 生成技术创作。每一扇窗户都是一个通向不可能世界的入口——极光下的冰岛苔原、海中喷发的火山、占满天空的木星、月球表面的孤寂、长江奔涌入室……

这些图像探索了"窗口"作为媒介的双重性：它既是物理空间的边界，又是想象力的起点。

## 技术栈

| 类别 | 技术 |
|------|------|
| 前端 | HTML5 + CSS3 + Vanilla JavaScript |
| 字体 | Playfair Display + Inter（Google Fonts） |
| 设计 | 暗色主题 · 毛玻璃导航 · 渐变叠加 |
| 画廊 | 响应式网格（3/2/1 列） · 全屏灯箱（← → ESC） |
| 图片 | WebP 缩略图 · JPEG 全尺寸（1600px） · 16KB hero 背景 |
| 安全 | CSP · X-Content-Type-Options · frame-ancestors · 邮箱混淆 |
| 部署 | GitHub Pages · 强制 HTTPS · `yaohaixu.online` 自定义域名 |

## 分支策略

```
main ── 稳定发布版（GitHub Pages 生产环境）
 │
 dev ──── 开发版（日常开发，测试通过后合入 main）
```
